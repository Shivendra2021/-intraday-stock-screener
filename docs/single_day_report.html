Intraday Stock Screener - Single Day Execution Report

This document details the expected execution timeline, architecture, and configuration of the Intraday Stock Screener across a single trading day.

Timeline Phases

1. Pre-Market (08:30–09:15 AM IST)

System initializes, loads configuration, and authenticates with the broker. Pre-market gap analysis is performed.

🚀 [SYSTEM START] Intraday Screener Initialized ✅ Broker Auth Successful 📊 Pre-Market Gap Analysis Completed

2. ORB Phase (09:15–10:15 AM IST)

Opening Range Breakout (ORB) monitoring. The system tracks the first 15-minute high and low, alerting on breakouts.

🔥 [ORB ALERT] RELIANCE Breakout Direction: BULLISH (Above 15m High) Price: 2540.50 Target: 2560.00 Stop-loss: 2530.00

3. Midday VWAP Phase (10:15 AM–12:30 PM IST)

Focus shifts to VWAP and moving average strategies as morning volatility settles.

📈 [VWAP ALERT] INFY Signal: Price crossed above VWAP Price: 1450.20 VWAP: 1445.50 Volume: 2.5x Average

4. Afternoon Surge (12:30–02:15 PM IST)

Monitoring for European market opening effects and afternoon breakout setups.

⚡ [AFTERNOON SURGE] HDFCBANK Volume Spike Detected! Price: 1620.00 (+1.5%)

5. Square-Off (02:15–03:30 PM IST)

No new positions are initiated. Open positions are managed for trailing stop-losses or squared off before market close.

⚠️ [SQUARE-OFF WARNING] Time: 03:10 PM IST Closing all open positions in 5 minutes.

6. EOD Reconciliation (03:30–04:00 PM IST)

Final summary report generation, log rotation, and system shutdown.

📊 [EOD SUMMARY] Total Trades: 5 Winners: 3 Losers: 2 Net PnL: +₹4,500 System Shutting Down. See you tomorrow!

Module Architecture

Module Description
main.py Entry point, scheduler, and main execution loop.
data_fetcher.py Handles API calls to broker for quotes and historical data.
strategy_orb.py Logic for Opening Range Breakout detection.
strategy_vwap.py Logic for VWAP mean reversion and trend following.
telegram_notifier.py Formatting and sending alerts via Telegram Bot API.

Configuration Reference

Key Default Description
RISK_REWARD_RATIO 1:2 Minimum required RR for trade alerts.
MAX_TRADES_PER_DAY 10 Hard limit on number of alerts/trades to prevent overtrading.
ORB_TIMEFRAME_MINS 15 Timeframe used for Opening Range calculation.
